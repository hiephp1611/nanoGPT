# nanoGPT
 
 (Neural Network) Generatively Pretrained Transformer (GPT) learning project following lecture by Andrej Karpathy:
 https://www.youtube.com/watch?v=kCc8FmEb1nY

 Minimal GPT training stack in PyTorch: dataset prep, GPT model, training loop (DDP-ready), and sampler. Supports tiny character-level runs up to small GPT-2–style configs and quick fine-tuning on your own text.
